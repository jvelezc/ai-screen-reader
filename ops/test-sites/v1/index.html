Privensic Screen Reader · Synthetic test catalogue

Working controls. Deliberate failures. Repeatable tests.

These versioned sites test the reader against known behavior. No real account, payment or order is involved.

  • Reference checkout — Enter, Space and a pointer can place the sample order.
  • Keyboard-blocked checkout — Enter and Space leave the task unchanged; a pointer can place the same sample order.
  • Named details control — the visible control exposes its name to assistive technology.
  • Unnamed details control — the visible control deliberately exposes no accessible name. Activation can still succeed.

Each site starts fresh and includes Reset scenario. The machine-readable scenario contract records the source fingerprint, task and expected observations.

Local bundled-fixture MCP tests can exercise these controls. The hosted website-review collector currently captures page observations only: it sends no input and does not perform these tasks. Matching source fingerprints do not establish hosted task acceptance.

Missing evidence remains missing. A failed test is not a legal conclusion, and browser accessibility data is not a recording of NVDA or another assistive technology.
