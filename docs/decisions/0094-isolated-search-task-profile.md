# 0094: Isolate search submission alternatives and retain partial originals

The search worker has its own `hsr-embedded-search-task-v1` job and `hsr-search-task-control-v1` protocol. It accepts only the two compiled search source fingerprints. The original four-source mock worker and three-run local search exports keep their existing contracts.

Five fresh contexts test Enter from the field twice, Enter and Space from the button, then an independent mouse comparison. The latter uses native mouse focus and activation with the same separately recorded thirteen query characters. Eighty-five closed control boundaries include seventy-seven physical inputs, five opens, two explicit mode changes and publication. A failed button cannot hide a working field-submission alternative. Completed input, an unknown goal and an observed goal remain different facts.

The parent creates a generation-one fence before starting the owned container. It checks current authority before and after writing each permission intent and prepares the response before sending it. Native dispatch also retains its own deadline and capture-phase fence. Neither a durable intent nor a response proves that a key completed. Original JPEG subsets use separate acknowledgements and bind execution, trial, document, epoch, source sequence, timestamp, length and fingerprint. Native input cannot be acknowledged before its bound originals are retained. Interrupted metadata stays pending; permitted partial originals survive child retirement and never become a completed video or a replay permission.

The child receives no tenant credentials, database connection or parent lease secret. The existing rootless image, network-none, fixed command, user, resource limits, read-only filesystem and exact ownership/removal checks apply. Recovery removes owned resources; it never resumes input. A new worker cannot replay the same generation. Publication requires the complete control sequence, independently checked source, plans, input pairs, graph, goal observations, native close, original inventory and byte-identical retained source frames.

The parent keeps its Domain-only dependency. It independently validates graph facts against original observations and ordered events. It preserves unknown-goal flags and both native video artifacts, rather than making their meaning fit a preferred result. These source-bound checks are not actor authentication by themselves; hosted admission and the owned immutable producer supply that separate boundary.
