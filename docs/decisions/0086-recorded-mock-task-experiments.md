# 0086: Record independent mock task experiments before hosted task admission

The v1 lab catalogue now has a closed local recording path. It records the exact
embedded working/broken checkout and named/unnamed-control sources without
borrowing synthetic-shop provenance or enabling public website input.

For one scenario, collect three fresh keyboard experiments (Enter, Enter, Space)
and a fourth fresh pointer comparison. Each run has its own document/run identity.
Keyboard inputs remain reader events and graph edges; the pointer experiment has
separate before/after observations, attempted/completed input and goal facts.
The pointer channel accepts only the fixed action in verified embedded sources.
It cannot receive a URL, selector, script, credential or caller-authored task.

The existing recorder owns capture admission, exclusion, original WebM, precise
source JPEGs and native shutdown. Its existing three-frame startup rule remains
unchanged for animated calibration fixtures. Static mock pages may start after
one genuine source frame; the same five-second startup deadline remains in force.
No artificial pixels or page animation are inserted into the original source.

The v1 pages lack calibration markers. Retain their original video and source
timestamps, but mark event-to-video alignment unverified and provide no inferred
seek cues. The passive viewer plays the whole clip; graph selection retains the
actual state/action transcript without claiming a verified video position.

`--record-mock-tasks <scenario> <new-directory>` exports a local folder and ZIP
with three keyboard reports/graphs/recordings, pointer recording/observations,
exact source text and a bounded file manifest. The manifest retains source hash,
producer assembly hash/version, runtime/platform, viewport and independent run IDs.
`--verify-mock-tasks <directory> <trusted-manifest-sha256>` checks exact inventory,
source/scope and actual file hashes. It rejects extra, pending and changed files,
invented synchronization, legal claims and different source/input descriptors.
The manifest digest must be retained separately. Hash correspondence alone does
not authenticate the collector, time, custody or legal admissibility.

A comparison summary requires complete input records, actual goal observations,
independent experiments, matching source, media and confirmed capture/shutdown.
Missing or inconsistent evidence stays incomplete. A repeatable absence of the
goal after these tested keyboard routes is not a global unreachability claim.
`Unknown`/`TimedOut` remains unchanged in each original reader receipt. The
website evidence assessment remains `NotAssessed`; legal case determination is
always false.

## Independent Maestro check

Use the configured private Maestro web worker for served-page UI checks and
screenshots. The four source-controlled flows at `ops/test-sites/maestro/v1/`
assert the action is visible, the goal initially hidden, and a pointer click
reveals the goal; they save before/after screenshots. Ground selectors in the
authored stable IDs. The interactive hierarchy tool returned an empty view in
this run; its output was not used as proof. Require the complete flow/JUnit result.
Maestro screenshots keep their own run identity and cannot become the screen
reader's keyboard events, original captures or recordings.
