# 0092: Keep recorded search experiments separate from admitted v1 mock tasks

Status: implemented in source, November15,2026. Hosted search admission remains a separate gate.

The fixed-query reader extension is ready for recorded experiments. Silently adding its sources to the existing four-source mock catalogue would let a thirteen-character command pass through a control profile that authorizes whole commands. That is insufficient authority for future hosted input after lease loss.

Add a separate, source-bound local search recorder and manifest. Three fresh contexts perform Enter, Enter and Space; a fourth performs native mouse focus, the same explicitly recorded keyboard query and native mouse activation. Retain the original source, all input pairs, states/edges, reader output, source JPEGs, complete original WebM files, capture closure and native shutdown. The pointer graph retains additional actual before-snapshots without inventing continuity across them.

Save each keyboard attempt before deciding to continue. Any incomplete input, media, capture or shutdown evidence stops further input. A completed activation whose goal times out may qualify for a deliberate independent repeat only when every native key has its matching completion, all observations are retained and cleanup is confirmed. Goal uncertainty is not the same fact as missing native-input completion.

The verifier checks a separately retained manifest digest, bounded exact inventory and source identity, then recomputes structured summaries, graphs and comparison outcomes from the saved records. HTML is bound to the trusted inventory and belongs to its producing release; future cosmetic rendering changes must not invalidate historical bytes. Verification does not rerender originals. This is local integrity verification, not collector authentication or tenant evidence admission. Unknown marker alignment, absent external assistive-technology validation and legal scope remain explicit.

Existing v1 mock source IDs, worker boundaries, manifests, API/MCP authority and public task behavior remain unchanged. Hosted search requires a separately versioned job and control protocol, durable authorization immediately before each native character and pointer action, no-replay fencing, independent parent validation, and scoped original publication before the Edge consumer can offer it.
