# 0017: Bounded authored traversal with immutable evidence

Status: implemented local slice, October 20, 2026.

The original milestone 2 needs attempt and graph contracts before recording, diagnosis and hosted storage can reference them. Add a substantive Exploration module depending only on Domain and ScreenReader. Domain holds immutable observations, plans, attempt receipts, outcome dimensions and graph records. CLI owns local files and human-readable rendering. Directory.Build.targets enforces the dependency and package boundaries.

An authored route has an explicit reader-visible precondition, destination predicate and 1..500 instructions. It runs on one caller-owned exclusive browser. The runner creates and owns its reader session; callers must not operate that browser concurrently. This local contract is not hosted controller fencing. It does not search arbitrary websites, invent free-text goal predicates, repair focus or replay input after an uncertain result.

Run bounds are 1..500 route commands, 1..500 consecutive unchanged observations, and a positive duration up to ten minutes; defaults are 30, 3 and 30 seconds. The separate initial ReadCurrent establishes the baseline. Reader verification retains its own bounded polling and browser capture deadline. Duration cancellation is cooperative: in-flight browser input must return before disposal; a stuck transport is not claimed to have stopped at the exact deadline. Every stop preserves the unattempted route count and its specific reason.

Each command attempt references the last retained source observation and, when reliable, the refreshed result observation; its own immutable ordered reader events preserve the intermediate refresh/input sequence. Source observations are point-in-time evidence, not a transaction locking a live page. The reader refreshes before actual input and checks document identity. A changing website can differ from that last retained source; this implementation does not claim a full snapshot for every verification poll or atomic state equality at dispatch.

The final instruction verifies the explicit destination using existing reader semantics. A timeout or unchanged snapshot is Unknown. An observed disabled control is a route-scoped barrier and NotReached. A policy denial, stale document, reader limitation, browser error or cancellation is separate from an accessibility barrier. A browser failure or interrupted post-input observation retains attempted/completed input and uncertainty; it creates no reliable result edge. There are no automatic retries.

Graph projection is versioned and rebuildable from the receipt. Each retained observation gets a distinct graph node, including repeated states, different same-URL states and new document instances. Every result edge points to an actual observation, never the requested but unobserved goal. Invalid or duplicate evidence references are rejected. No state clustering or cross-session identity matching is implemented.

The `same-document-reader-state-v1` fingerprint includes normalized reader snapshot, document/frame identity, mode and cursor. It omits DocumentUrl entirely. It detects exact unchanged states within this execution; changing node instances are conservatively different. It proves neither safe replay nor whole-site equivalence. Existing editable-value/descendant exclusions apply, but this local synthetic-fixture artifact path is not a general privacy protocol for authenticated sites.

The receipt records monotonic command/observation timing, UTC start, a unique run ID, profile/schema, ordered events and separate execution/reachability/barrier/policy dimensions. Key attempts and completed keyboard API calls are effort metrics, not a calibrated burden score. Assistance is explicitly absent because this runner has no human input channel. Recording is explicitly unavailable.

The CLI runs four alternatives in fresh contexts: success, disabled control, validation dialog instead of the destination, and unchanged feedback. It writes one unique batch folder with append-only JSON and Markdown files. Writes stage in `.pending` files and publish by rename; incomplete writes remain visible. Original artifacts are never replaced. Browser cancellation does not cancel saving its completed/uncertain input receipt. Files are local evidence, not a durable hosted store or fsync/recovery guarantee.

The Markdown report provides the traversal table, observation links and event anchors without scripts, live connections or replay. Page text is escaped, and URLs are omitted from snapshots. JSON retains the full scoped evidence and graph. Milestone 2 remains open for recording, synchronization, feature diagnostics, richer viewing and separately authorized replay.
