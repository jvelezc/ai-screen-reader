# 0060 Fixed keyboard recordings under an admitted worker attempt

October 28, 2026. Core HTTP contract **1.8.0** adds `traversalRoute: 1..4` to
fixed-fixture admission and private `scan_start_fixture`. The four routes are
checkout preview, disabled checkout, validation dialog and unchanged feedback.
No caller-supplied URL, commands, predicates or credential entry is admitted.
Default and passive modes remain available; keyboard and passive request options
cannot be combined. A retry must retain the original request ID and route.

The Domain catalog supplies the same authored plans used by the local recorder.
The credential-free isolated CLI child runs the existing real Chromium collector,
acknowledges capture exclusion and shutdown, decodes the original WebM and retains
the actual receipt, source/action/result graph, measured clock samples, marker
frames and timing uncertainty. Reached, observed-disabled and Unknown/TimedOut
outcomes remain independent. A collection error blocks the attempt; this slice
does not publish incomplete or cancelled media as a complete package.

Five producer originals are retained: `observation.json`, `traversal.json`,
`original.webm`, `source-frames.zip` and `evidence-manifest.json`. The observation
is explicitly a **pre-traversal baseline**. Its zero-input/no-goal fields must
never replace the actual route's attempted/completed keys or verified outcome.
`traversal.json` retains the actual collector assembly SHA/version; the producer
manifest retains the actual admitted job, generation and worker. Source JPEGs
are a bounded exact-entry archive, verified without extracting supplied paths.

The child transport is capped at 25 MiB. Parent validation checks the fixed plan,
baseline equality, job and hash bindings, graph references and input events,
source JPEG inventory, decoded frames and capture closure before persistence.
Independent owned-container absence and complete original/index readback precede
the existing fenced completion transaction. Recovery never reexecutes input.

Migration `20261028092549_admitted_keyboard_recordings.sql` adds a typed route
and membership-checked admission. Mode/route-safe retries conflict on changes.
Legacy and passive-only workers defer keyboard jobs before allocating a lease.
Only the worker can call the new traversal-aware claim function. Existing
worker/generation/token completion fencing remains in force.

HTTP and private MCP expose the same admission and original-file reads. The
Lovable notebook consumes them through the existing project's Edge function.
It verifies all five originals before exposing the actual graph, event timeline
and native video player. Account loss or reconnect aborts reads and revokes owned
media URLs. Selecting evidence sends no live input and does not autoplay video.

This is a controlled synthetic collection capability. It does not establish an
arbitrary website barrier, a human/NVDA encounter, custody, plaintiff eligibility
or admissibility. The next gate binds scanner assertions to independently
verified recorded events in the automated assessment, followed by broader
hosted recovery/authority acceptance. Public MCP/plugin publication is deferred.
