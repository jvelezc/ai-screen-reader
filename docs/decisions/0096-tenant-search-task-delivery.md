# Independent tenant search demonstrations

Controlled search experiments use their own workspace job family. They are never attached to an entered customer website as findings. A source is one of two exact embedded identities; callers cannot supply a URL, selector or query. Four fresh keyboard contexts and a separate pointer context preserve the native input, reader, graph and media correspondence already validated by the collector.

The current application session and organization membership authorize idempotent admission. The original creator/session also remain live for every native input grant and publication lease. Generation one cannot be reclaimed after interruption. A storage-only lease can publish retained originals at most three times; it preserves the original producer/execution, waits after a failed publication and never invokes a browser. Invalid original data is terminal. Publication attempts retain closed reasons, immutable fingerprints and explicit input-not-retried facts.

The archive has its own logical schema over the existing private bounded hash-object store. Exact inner ZIP parts are at most4MiB and the index is committed last. Local originals are verified before acquiring publication authority; optional S3 originals are reconstructed and semantically verified before committing a completed job. No credentials enter the browser child, originals or logs. Reusing the physical store does not relabel this archive as a legacy traversal receipt.

HTTP1.24 exposes eight separate operations: admission, latest status, exact status, cancellation, result, file inventory, original bytes and publication diagnostics. Private MCP adds seven corresponding tools; its status tool handles latest/exact reads. Source and original claims are validated at both consumption boundaries. Every original read rechecks current caller/workspace and immutable job before and after retrieval, including failure. Numeric sorted file IDs and pinned index hashes avoid accepting arbitrary paths. Consumers verify page/whole-file hashes and reauthorize at exact EOF before delivery. Original HTML is data, not an executable application surface.

The Lovable application remains a third-party consumer through the existing Supabase Edge function. Core API/private MCP source acceptance, hosted migration, exact artifact promotion, Edge delivery and original-account UI playback are separate gates. Search demonstrations remain distinct from a supported public-search profile.
