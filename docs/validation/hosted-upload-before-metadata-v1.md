## Requirement and scope

One actual upload/metadata boundary is documented; database completion is never
inferred from received bytes or a timeout. Recovery cannot dispatch input or
manufacture a replacement attempt. Original scope and bytes survive, all owned
guards settle, and the distinct normal job works. A missing or failed transfer
remains unavailable until separately proven. The next separate gate is an actual
[scoped worker-to-storage outage](hosted-storage-outage-v1.md). Broader provider failures,
external collection, intervention and operations remain separate gates.
