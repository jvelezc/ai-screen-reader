# Public service navigation task v1

This increment closes the gap between a passive page review and an attempted public task. The core API1.20 and private MCP admit one independently fenced task for the exact completed review and original digest. The Lovable consumer uses only the existing Supabase Edge gateway.

## Scope and recorded facts

The collector selects an observed, visible pricing, course catalog, contact or help hyperlink on the approved HTTPS host. It opens three fresh anonymous browser contexts: two keyboard attempts, followed by a separate mouse comparison. Each keyboard attempt permits at most48 Tab presses and one Enter on that exact observed anchor. The task driver sends no form values, credentials, purchases or caller-authored selectors. GET/HEAD policy and the independent network fence remain mandatory.

Each original report contains organization, parent review, job, request, generation, producer and native execution identity. Before/after accessibility snapshots, actual input events, original WebM recordings and their SHA-256 inventory are bound inside that report. Node identities match accessibility snapshots. The graph is a projection of actual focus/document states and attempted/completed input edges; unknown focus remains explicit. It does not establish global reachability or universal unreachability.

A recording is decoded after capture exclusion acknowledges collector stop and Chromium/process shutdown joins. Uncertain input still retains permitted recordings and observations when they can be verified. Recordings have no audio; event-to-video seek alignment is explicitly unverified. Playback reads originals and sends no website input.

## Evidence decision

The core derives eight named conditions: meaningful task, recorded barrier, exact trigger, accessibility context, repeated failure, pointer comparison, reproducible environment and original artifacts. A ready website package requires two complete keyboard failures at the same actual activation, a successful independent pointer comparison, original snapshots/media, no unresolved policy/engine interruption, confirmed native removal and original readback. A48-Tab search without activation cannot establish that barrier. An unchanged URL with changed inline content remains unconfirmed; the collector does not infer failure from URL alone. Known accessibility context, test conditions and verified originals remain recorded even when the task outcome is uncertain. Two successful keyboard attempts cover only the tested task. All other incomplete or uncertain combinations retain their missing conditions.

These outcomes do not establish disability, personal injury, standing, legal liability, admissibility, conformance or actual NVDA behavior. Checkout, account workflows, forms, cross-host tasks and privacy choices are outside this task profile.

## Authority and recovery

Task admission takes only a fresh request UUID and the parent original digest. The source comes from the completed review. Original caller identity, membership and application session are checked in the fixed project. The original auth.sessions row and its expiration are checked before each grant/renewal. Browser children receive no JWT, database, deployment or S3 credentials.

The worker writes a one-shot execution fence and each possible-input intent durably before issuing a hash-bound acknowledgement. Cancellation and expiration revoke future grants. Lost admission responses reconcile the same UUID; expiration, crashes and reconnect never requeue input. Separate task ownership journals allow only exact owned container/network cleanup. Root deployment recovery must retire retained task intents before promotion or rollback. An older binary unable to prove that cleanup holds closed.

Original/result reads reauthorize around storage work, including exact EOF. Recordings are served through the scoped API in64KiB pages, never by a public or signed S3 URL. Consumers verify every page, the whole file against the pinned report inventory, and fresh EOF before playback or export. Sign-out, workspace changes and access denials clear private results and blob URLs.
